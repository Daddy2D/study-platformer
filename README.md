# Мини-платформер

Учебный 2D-платформер на JavaScript и Canvas с редактором уровней.
Игра, редактор и настройки — три страницы одного проекта на Vite.

В проект входит игра, стартовое меню, жизни, простые звуки, восемь уровней,
три боя с боссами и отдельный редактор уровней.

## Как запустить

1. Один раз установить зависимости: `npm install`.
2. Запустить сервер разработки: `npm run dev` и открыть адрес из подсказки.
3. Собрать статику для раздачи: `npm run build`, проверить сборку — `npm run preview`.
4. Редактор — `editor.html`, настройки — `settings.html`; они же открываются
   из меню игры.

Открыть `index.html` двойным щелчком больше нельзя: браузер не загружает
ES-модули с диска. Нужен `npm run dev` или собранная папка `dist`.

## Проверки

- `npm run lint` — правила ESLint;
- `npm test` — тесты Vitest;
- `npm run build` — сборка трёх страниц в `dist/`.

Перед коммитом проходят все три команды.

## Что есть в игре

- Стартовое меню: «Играть»/«Продолжить», «Уровни», «Мои уровни»,
  «Достижения», «Настройки уровней», «Редактор уровней», звук.
- Восемь готовых уровней: пять переработанных карт, арена босса,
  снежные вершины со вторым боссом и каменный замок с третьим.
- Три жизни на каждый уровень. После потери жизни игрок возвращается
  на последний чекпоинт и ненадолго становится неуязвимым.
- Батут и падающие платформы.
- Босс с тремя ударами, двумя фазами и простыми снарядами.
- Снежный биом: зимний фон, снежная земля, снегопад и второй босс.
- Каменный замок: каменные стены, окна с огнями и третий босс.
- Настройки для каждого уровня: гравитация, прыжок, скорость, жизни,
  враги, батут и платформы. Есть готовые пресеты.
- Прогресс кампании: звёзды за уровни, лучшее время, сохранённые жизни
  и достижения.
- Таймер прохождения и кнопка «Продолжить» в меню.
- Частицы при монетах, ударах и приземлении, лёгкая тряска экрана
  при уроне и покачивание игрока при беге.
- Новые механики: платформы в одну сторону, разрушаемые блоки,
  лестницы, пилы и пушки.
- Экран проигрыша, когда жизни закончились.
- Короткие звуки: прыжок, монета, ключ, дверь, чекпоинт, стомп, урон,
  батут, треск платформы, рык и победа над боссом.
- Свои уровни из редактора сохраняются в браузере и появляются в меню
  «Мои уровни».
- Экран финала с итоговыми очками.

## Управление

| Клавиши | Действие |
|---|---|
| `←` `→` или `A` `D` | Движение |
| `Space`, `↑` или `W` | Прыжок (в воздухе доступен второй прыжок) |
| `R` | Начать текущий уровень заново |
| `P` или `Esc` | Пауза |
| `Q` | Выйти в главное меню |
| `M` | Включить или выключить звук |
| `↑` `↓`, `Enter` | Выбор пункта меню |
| Мышь | Кнопки меню, выбор уровня |

## Жизни и проигрыш

На каждый уровень даётся 3 жизни. Жизнь отнимают шипы, враги, пули,
босс, падение в яму и раздавливание платформой. После урона игрок появляется
на последнем чекпоинте и мигает — в это время он неуязвим.

Когда жизни закончились, появляется экран «Игра окончена»:
можно начать уровень заново или выйти в меню.

Количество жизней и время неуязвимости меняются в `settings.js`:

```js
startLives: 3,
invulnerabilityTime: 90
```

`invulnerabilityTime` — это кадры. 60 кадров примерно равны одной секунде.

## Батут и падающая платформа

Батут `B` стоит на земле. Если наступить на него сверху, игрок высоко
подпрыгивает. Батут удобен, чтобы добраться до верхних монет или
секретного маршрута.

Падающая платформа `L` сначала дрожит, потом исчезает. Через несколько
секунд она появляется на прежнем месте. Переходить по таким платформам
нужно быстро, но без спешки: если платформа упала, можно подождать
и попробовать снова.

Настройки обеих механик лежат в `settings.js`:

```js
springForce: -18.5,
fallingShakeTime: 34,
fallingRespawnTime: 150
```

## Босс

Шестой уровень — арена первого босса. Он выдерживает три удара прыжком
по голове. После второго удара начинается вторая фаза: босс двигается
быстрее, чаще прыгает и стреляет сразу тремя снарядами.

Седьмой уровень — снежные вершины и второй босс, Ледяной страж.
У него больше здоровья, он быстрее и во второй фазе стреляет веером
из пяти ледяных снарядов.

Восьмой уровень — каменный замок и третий босс, Каменный страж.
У него пять ударов здоровья, тяжёлые огненные снаряды и широкий веер
атак во второй фазе.

Удар по голове засчитывается, даже если босс прыгает навстречу.
После успешного попадания есть короткая защита от повторного урона.
Если игрок задел верхнюю часть босса, его отталкивает, а жизнь не снимается.

Пока босс жив, финишный флаг закрыт. После победы появляется надпись
«Финиш открыт», и можно идти к флагу `X`.

Если игрок теряет жизнь на арене, босс возвращается на стартовую позицию,
но уже полученные удары сохраняются. Полностью бой сбрасывается только
при перезапуске уровня клавишей `R`.

Здоровье босса показывается полосой в правом верхнем углу. Все числа
для боя собраны в `settings.js` в разделе «БОСС».

## Биомы

В игре три биома:

- `grass` — обычные зелёные холмы;
- `snow` — снежные вершины: зимний фон, горы, снежная земля и снегопад;
- `castle` — каменный замок: тёмный фон, стены с окнами и каменная земля.

Биом выбирается в `levels/levels-list.js` массивом `LEVEL_BIOMES`.
В редакторе для своих уровней есть переключатель
«Обычный / Снежный / Замок»; выбор сохраняется в JSON и в черновике.
В игре свои уровни с биомами `snow` и `castle` получают своё оформление.

## Прогресс, звёзды и рекорды

Для каждого готового уровня сохраняются:

- пройден ли уровень;
- лучшее время;
- лучшее количество оставшихся жизней;
- лучшее количество собранных монет;
- звёзды;
- число попыток.

Звёзды выдаются так:

- 1 звезда — уровень пройден;
- 2 звезды — собраны все монеты **или** не потеряна ни одна жизнь;
- 3 звезды — и все монеты, и ни одной потерянной жизни.

Время показывается в HUD во время игры. После прохождения появляется
итог: время, монеты, жизни, звёзды и лучшее время. На экране выбора
уровня видны звёзды и рекорд каждого уровня.

В главном меню первая кнопка становится «Продолжить» и открывает первый
непройденный уровень. Если пройдены все уровни, кнопка называется
«Начать заново».

Экран «Достижения» показывает общую статистику и восемь достижений:
первый пройденный уровень, все монеты, прохождение без урона, победа
над боссом, все уровни, 50 монет, быстрый уровень и 15 звёзд.

Прогресс хранится в `localStorage` под ключом `platformer.progress.v1`.
Он не переносится на другой компьютер автоматически.

## Новые механики

- `O` — **платформа в одну сторону**. На неё можно запрыгнуть сверху,
  а снизу и сбоку игрок проходит сквозь неё.
- `R` — **разрушаемый блок**. Он твёрдый, но ломается, если ударить
  его головой снизу.
- `H` — **лестница**. На ней можно висеть и двигаться вверх-вниз
  клавишами `↑`/`↓` или `W`/`S`.
- `W` — **пила**. Ездит влево-вправо и наносит урон при касании.
- `N` — **пушка**. Стреляет в сторону игрока, когда он подходит близко.

Все механики доступны в палитре редактора. В шаблоне
«Новые механики» есть пример с каждой из них.

В кампании механики появляются постепенно:

- `O` — на первом уровне, над первой ямой;
- `H` — на втором уровне, рядом со стартом;
- `R` — на третьем уровне, в секретной нише над платформой;
- `N` — на четвёртом уровне, на земле в пещере;
- `W` — на пятом уровне, на верхней платформе после двери.

## Звук

Все звуки генерируются кодом через WebAudio, отдельных mp3/wav файлов нет.
Браузер включает звук только после первого нажатия клавиши или клика —
это нормально.

Клавиша `M` и пункт «Звук» в меню выключают и включают звук.
Выбор запоминается в браузере.

## Эффекты

В игре есть простые частицы и анимация:

- искры при сборе монет и ключей;
- пыль при приземлении;
- разноцветные частицы при ударе по врагу и боссу;
- красные частицы и тряска экрана при потере жизни;
- лёгкое покачивание игрока при беге.

Все эффекты рисуются кодом на Canvas, отдельных файлов с анимациями нет.
Их можно отключить или изменить в `js/effects.js`.

## Свои уровни

Уровни, созданные в редакторе, сохраняются в `localStorage` браузера
под ключом `platformer.customLevels.v1`. Они не отправляются в интернет
и не появятся на другом компьютере автоматически.

Чтобы перенести уровень:

1. В редакторе нажать «Скачать JSON».
2. Передать файл.
3. На другом компьютере нажать «Загрузить JSON» и выбрать файл.

Если для уровня были заданы биом или настройки, они тоже попадут в JSON.
При импорте они применятся после сохранения уровня в редакторе.

Свои уровни можно запускать из меню «Мои уровни» или по ссылке
`index.html?play=<id>`.

## Настройки уровней

Страница `settings.html` открывается из меню игры кнопкой
«Настройки уровней». Настройки задаются **отдельно для каждого уровня**:
можно выбрать готовый уровень или свой.

Что можно менять:

| Настройка | Диапазон | Обычное значение |
|---|---|---|
| Гравитация | 0.3–1.2 | 0.6 |
| Сила прыжка | −16…−8 | −13 |
| Прыжков всего | 1–3 | 2 |
| Скорость игрока | 3–8 | 5 |
| Жизни | 1–5 | 3 |
| Скорость врагов | 0.5–3 | 1.7 |
| Сила батута | −24…−12 | −18.5 |
| Скорость платформ → | 0.5–3 | 1.4 |
| Скорость платформ ↑ | 0.5–3 | 1.0 |

В разделе «Расширенные настройки» можно менять:

- время неуязвимости после урона;
- дальность, задержку и скорость пуль стрелка;
- время дрожания и возвращения падающих платформ;
- дальность движения платформ;
- здоровье, скорость, прыжки и снаряды босса.

Есть готовые пресеты: «Обычно», «Легко», «Сложно» и «Луна».
Пресет заполняет поля, но применяется только после кнопки «Сохранить».

Кнопка «Сбросить к обычным» удаляет настройки выбранного уровня.
Кнопка «Проверить в игре» сохраняет настройки и открывает уровень
в новой вкладке.

Настройки хранятся в `localStorage` под ключом
`platformer.levelSettings.v1`. Для готового уровня используется ключ
`builtin:<номер>` (нумерация с нуля), для своего — `custom:<id>`.

Если игра уже открыта, после сохранения настроек нажми `R`,
чтобы перезапустить текущий уровень с новыми значениями.

Готовый уровень можно открыть по ссылке `index.html?level=<номер>`,
где номер начинается с нуля. Например, `index.html?level=0` — первый уровень.

## Редактор уровней

Открывается из меню игры или файлом `editor.html`.

Что умеет редактор:

- палитра клеток: земля, старт, финиш, монеты, враги, шипы, чекпоинт,
  платформы, ключ, дверь, батут, падающая платформа, платформа
  в одну сторону, разрушаемый блок, лестница, пила, пушка и босс;
- выбор биома: **Обычный**, **Снежный** или **Замок**. Биом сохраняется вместе
  с уровнем и применяется при проверке и запуске;
- рисование мышью, ластик и стирание правой кнопкой;
- заливка прямоугольником;
- выделение области и копирование/вставка фрагментов;
- изменение ширины и высоты карты;
- отмена и возврат действий;
- автосохранение черновика: карта не потеряется, если закрыть вкладку
  без кнопки «Сохранить»;
- готовые шаблоны: пустой уровень, платформы, снежные вершины,
  каменный замок, новые механики, высокая башня, пещера со стрелками
  и арена босса;
- мини-карта с переходом к старту и финишу;
- проверка карты: есть ли старт `P` и финиш `X`, не висит ли старт в воздухе,
  есть ли ключ для двери, не перепрыгивается ли дверь без земли над ней,
  не поставлено ли несколько боссов `Z`;
- сохранение в браузере и удаление своих уровней;
- загрузка готовых уровней и своих сохранённых карт;
- проверка уровня в новой вкладке;
- скачивание и загрузка JSON.

Горячие клавиши редактора:

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` | Отменить |
| `Ctrl+Y` или `Ctrl+Shift+Z` | Вернуть |
| `Ctrl+S` | Сохранить |
| `Ctrl+C` | Копировать выделение |
| `Ctrl+V` | Вставить скопированное |
| `Ctrl+X` | Вырезать выделение |
| `B` | Кисть |
| `E` | Ластик |
| `R` | Прямоугольник |
| `S` | Выделение |
| `Esc` | Выйти из режима выделения или вставки |
| `Delete` / `Backspace` | Очистить выделение |

Черновик редактора хранится в `localStorage` под ключом
`platformer.editorDraft.v1`. После успешного сохранения уровня
черновик очищается.

Кнопка «Проверить» сохраняет черновик в браузере и открывает
`index.html?test=1` в новой вкладке. Если браузер блокирует вкладку,
нужно разрешить всплывающие окна.

Для больших карт используйте мини-карту: она показывает всю карту
и текущую видимую область. Нажатие на мини-карту перемещает к этому
месту, а кнопки «К старту» и «К финишу» помогают быстро найти `P` и `X`.

## Как устроена карта уровня

Уровень — это массив строк одинаковой длины. Один символ = одна клетка 48×48.

| Символ | Значение |
|---|---|
| `.` | пусто |
| `G` | земля |
| `P` | старт игрока (обязателен) |
| `X` | финишный флаг (обязателен) |
| `C` | монета |
| `E` | обычный враг |
| `T` | стреляющий враг |
| `S` | шипы |
| `F` | чекпоинт |
| `M` | платформа, движущаяся по горизонтали |
| `V` | платформа, движущаяся по вертикали |
| `K` | ключ |
| `D` | дверь (занимает 2 клетки в высоту) |
| `B` | батут |
| `L` | падающая платформа |
| `O` | платформа в одну сторону |
| `R` | разрушаемый блок |
| `H` | лестница |
| `W` | пила |
| `N` | пушка |
| `Z` | босс (на уровне может быть только один) |

Полезно помнить:

- Игрок появляется в клетке `P`, поставив ноги на нижнюю границу клетки.
- Дверь `D` ставится на землю и занимает 2 клетки. Чтобы её нельзя было
  перепрыгнуть без ключа, сверху над дверью ставят `G`.
- Движущаяся платформа `M` или `V` ставится в пустую клетку.
  Дальность движения задаётся в `settings.js`.
- Урон от шипов `S` считается по зонам у видимых треугольников,
  а не по всей клетке. Поэтому прозрачные края тайла не ранят игрока.
- Батут `B` ставят на землю или на платформу. Он занимает нижнюю часть клетки.
- Падающую платформу `L` удобно ставить над ямой или между двумя обычными платформами.
- Босс `Z` ставится на землю и занимает примерно две клетки в высоту.
  Вокруг него нужно оставить место для прыжков и снарядов.
- Если строки разной длины, игра дополнит их точками и напишет
  предупреждение в консоль браузера. Редактор выравнивает строки сам.

`src/game/state.js` — единый объект состояния: массивы объектов уровня,
счётчики, текущий экран, флаги ввода. Модули меняют его поля через `state.*`.

## Как добавить готовый уровень

1. Создать `src/data/levels/level9.js` по образцу соседних:
   `export const LEVEL_9 = [ ... ];`
2. Добавить импорт и карту в `src/data/levels/index.js` — массив `LEVELS`.
3. Добавить название в `LEVEL_NAMES`, биом в `LEVEL_BIOMES`
   и тип босса в `LEVEL_BOSS_TYPES`, если он нужен.
4. Прогнать `npm test` (тесты проверяют реестр уровней) и открыть игру
   через `npm run dev`.

## Настройки

Обычные значения всех параметров лежат в `settings.js`: сила прыжка,
гравитация, скорость игрока и врагов, скорость платформ, сила батута,
время падения платформ, здоровье и скорость босса, количество жизней,
время неуязвимости, задержка между уровнями, количество облаков.

Ученики меняют часть этих параметров на странице `settings.html`
отдельно для каждого уровня. Значения проверяются и ограничиваются,
чтобы игра не стала непроходимой. Остальные параметры (размер клетки,
FPS, высота двери, внутренние отступы) на странице не показываются.

## Идеи заданий для урока

- Нарисовать свой уровень из 20×10 клеток и пройти его.
- Сделать уровень без врагов, но с прыжками по платформам.
- Сделать уровень с ключом и дверью.
- Собрать короткий маршрут из батутов и падающих платформ.
- Придумать арену с боссом: где поставить платформы, чтобы до босса
  было удобно допрыгивать.
- Обменяться JSON-файлами с соседом и пройти чужой уровень.
- На странице настроек сделать уровень «лунным» и сравнить прыжки
  с обычными.
- Поменять в `settings.js` силу прыжка или здоровье босса и посмотреть,
  как изменится игра.

## Ограничения

- Свои уровни, настройки и прогресс хранятся только в текущем браузере.
- Звук включается после первого действия пользователя.
- Управление с телефона не предусмотрено.
- Исходная версия проекта сохранена в `_backup_original/`.
- Старые карты пяти уровней до переработки лежат в `_backup_levels_p1/`.
