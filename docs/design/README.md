# Дизайн StudyPlatformer

Оформление берётся из библиотеки дизайн-систем, а не выдумывается на каждой сессии.

- Источник: `E:\Daddy2D_Projects\tools\open-design-assets` (nexu-io/open-design, Apache 2.0)
- Карта «пакет → проект»: `INDEX.md` в той же папке.
- Здесь: **активный** набор в корне, альтернативы в `library/`.
- Во всех пакетах одни и те же 56 CSS-переменных, поэтому переключение — копирование двух файлов.

## Активный пакет: `friendly`

Учебный платформер с редактором уровней: интерфейс должен быть понятен школьнику и учителю, который впервые видит редактор. Тёплые цвета, крупные подписи, очевидные состояния кнопок. Редактор — самая сложная часть, и именно там мягкий стиль снижает страх «сломать».

Существующие стили проекта остаются источником истины для текущих экранов. `friendly` применяется к новым и при редизайне.

Редактор уровней, страница настроек и интерфейс на канвасе (меню, HUD, задания, пауза) переведены на `friendly`. Стили страниц подключают `tokens.css` через `@import`, офлайн-сборка вставляет токены в тот же `<style>`. Канвас не понимает CSS-переменные, поэтому читает их через `src/core/ui-palette.js`. Графика самих уровней (небо, земля, враги) остаётся прежней — это не интерфейс.

## Файлы

| Файл | Что внутри |
|---|---|
| `DESIGN.md` | замысел: палитра, типографика, компоненты, тени, do/don't |
| `tokens.css` | 56 переменных, готовых к вставке в `:root` |
| `library/friendly/` | пакет-источник: `DESIGN.md` + `tokens.css` |

## Правила

1. Цвета, радиусы, тени, типографическая шкала — только через `var(--*)` из `tokens.css`. Сырые hex вне `:root` не писать.
2. Новый компонент сначала ищется в `DESIGN.md` (раздел 4) и в `components.html` источника. Есть — повторяем форму и размеры, нет — добавляем описание в `DESIGN.md`.
3. Не смешивать два пакета в одном экране. Один экран — один набор токенов.
4. В редакторе уровней состояния (выбрано, нельзя поставить, изменено) различаются не только цветом — рамкой, курсором, подписью.
5. Инструменты редактора должны оставаться крупными: работа идёт мышью на школьном мониторе.
6. Страницы подключают `tokens.css` через `@import`. В офлайне `scripts/build-offline.mjs` подставляет токены сам, поэтому `@import` в архив не попадает.
7. Канвас берёт цвета и шрифт через `getUiPalette()` и `uiFont()` из `src/core/ui-palette.js`. Hex-цвета в отрисовке интерфейса не писать; графика уровней — отдельная история.
