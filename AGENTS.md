# «Мини-платформер» — инструкции для агента

Учебный HTML5-платформер с редактором уровней для кружка (дети 4–6 класса). Чистый JavaScript без сборки, классические `<script>` в `index.html`, глобальные переменные.

## Файлы

```
index.html            игра
editor.html           редактор уровней
settings.html         настройки уровней
settings.js           физика, жизни, скорость, размеры, задержки — источник правды
levels/level1..8.js   готовые карты (не менять)
levels/levels-list.js список уровней, названия, авторы
js/                   game, world, player, enemies, boss, render, effects,
                      input, sound, storage, progress, editor, settings-page, sprites
sprites/              28 изображений
css/                  стили игры, редактора, настроек
Пак_уровней(20.11.26)/ 10 JSON из редактора — работы детей, источник для переноса
_backup_original/     исходная версия проекта, не трогать
_backup_levels_p1/    старые карты пяти уровней, не трогать
README.md             механики, формат уровней, идеи для уроков
START_PROMPT.md       стартовое задание: цель, этапы, правила
```

## Команды

Сейчас: открыть `index.html` (игра), `editor.html` (редактор), `settings.html` (настройки) в браузере.

После этапа 2: `npm install`, `npm run dev`, `npm run build`, `npm test`, `npm run lint`.

Перед коммитом: сборка и тесты проходят, игра и редактор проверены руками.

## Формат уровня

Массив строк, клетка 48×48. Полный набор символов — множество `TILE_CHARS` в `js/world.js`:

`G` земля · `P` старт · `X` финиш · `C` монета · `E` враг · `T` стреляющий враг · `S` шипы · `F` чекпоинт · `M` платформа по горизонтали · `V` по вертикали · `K` ключ · `D` дверь · `B` батут · `L` падающая платформа · `O` платформа в одну сторону · `R` разрушаемый блок · `H` лестница · `W` пила · `N` пушка · `Z` босс.

README описывает только часть символов — при расхождении прав код.

JSON уровня: `{ version, name, rows: string[], updatedAt }`, у части уровней есть биом и настройки. Свои уровни в браузере: `localStorage`, ключ `platformer.customLevels.v1`.

## Правила

- Детские уровни неприкосновенны: доработка — исправление ошибок и совместимость, не переделка замысла.
- Уровни 1–8 не менять и не перенумеровывать. Новые уровни детей — с `level9` и далее.
- У каждого нового уровня обязательны: имя, биом, автор (имя ребёнка), одна строка «чем интересен». Автор показывается в списке и на экране победы.
- «Парашютист» и «Парашютист V2» остаются оба, но не рядом в списке.
- Паки уровней — группа в существующем списке, отдельного экрана не делать.
- Физику, баланс и настройки менять только по просьбе; правка цифр — отдельным коммитом с пояснением.
- Формат уровней менять только с обратной совместимостью и миграцией.
- Новые зависимости — только с обоснованием.
- Комментарии и интерфейс — по-русски, имена в коде — по-английски.
- Коммиты: `тип: что сделал`. Пушить в конце сессии.
