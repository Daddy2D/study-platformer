# «Мини-платформер» — инструкции для агента

Учебный HTML5-платформер с редактором уровней для кружка (дети 4–6 класса).
Vite, ES-модули, общее состояние игры — в `src/core/state.js`.

## Файлы

```

settings.html         настройки уровней
src/core/             settings (физика, жизни, скорость, размеры, задержки — источник
                      правды), storage, sound, input, canvas, sprites, effects, state
```

## Команды

`npm install` — один раз; `npm run dev` — сервер разработки;
`npm run build` — сборка в `dist/`; `npm run preview` — проверка сборки;
`npm test` — тесты; `npm run lint` — ESLint.

Перед коммитом: lint, тесты и сборка проходят, игра и редактор проверены руками.

## Формат уровня

Массив строк, клетка 48×48. Полный набор символов — множество `TILE_CHARS` в `src/game/world.js`:

`G` земля · `P` старт · `X` финиш · `C` монета · `E` враг · `T` стреляющий враг · `S` шипы · `F` чекпоинт · `M` платформа по горизонтали · `V` по вертикали · `K` ключ · `D` дверь · `B` батут · `L` падающая платформа · `O` платформа в одну сторону · `R` разрушаемый блок · `H` лестница · `W` пила · `N` пушка · `Z` босс.

README описывает формат и механики; при расхождении прав код.

JSON уровня: `{ version, name, rows: string[], updatedAt }`, у части уровней есть биом и настройки. Свои уровни в браузере: `localStorage`, ключ `platformer.customLevels.v1`.

## Правила

- Детские уровни неприкосновенны: доработка — исправление ошибок и совместимость, не переделка замысла.
- Уровни 1–8 не менять и не перенумеровывать. Уровни 9–16 — работы детей
  из пака; их можно исправлять, но не переделывать замысел.
- Ники авторов уровней 9–16 пока не вписаны (ждут от владельца), поле
  `author` в `LEVEL_META` пустое.
- У каждого нового уровня обязательны: имя, биом, автор (имя ребёнка), одна строка «чем интересен». Автор показывается в списке и на экране победы.
- «Парашютист» и «Парашютист V2» остаются оба, но не рядом в списке.
- Паки уровней — группа в существующем списке, отдельного экрана не делать.
- Физику, баланс и настройки менять только по просьбе; правка цифр — отдельным коммитом с пояснением.
- Формат уровней менять только с обратной совместимостью и миграцией.
- Новые зависимости — только с обоснованием.
- Комментарии и интерфейс — по-русски, имена в коде — по-английски.
- Коммиты: `тип: что сделал`. Пушить в конце сессии.

## Решения по авторам

- Автор подписывается ником: ребёнок вписывает его в редакторе, ник привязывается к уровню.
- Строка «чем интересен уровень» заполняется в редакторе и показывается в списке уровней.
- Автор показывается в списке уровней и на экране победы.
